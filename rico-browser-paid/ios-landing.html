RICO BROWSER MOBILE
🍎 VERSÃO WEB PARA IPHONE • BETA

Seu Rico Browser no iPhone.

Instale pela tela inicial do Safari, sem App Store e sem taxa de publicação da Apple. O acesso ao produto continua pago pelo sistema atual do Asaas.

O que funciona nesta versão inicial: salvar até 20 abas/links e abrir sites pelo Safari.
O que ainda não funciona: proxy individual por aba, sessões de navegação isoladas e aceleração de slots. Essa versão web não substitui todas as funções do Android.
ADQUIRIR ACESSO PELO ASAAS
Se você comprou neste mesmo navegador, o código é preenchido automaticamente. Guarde-o para recuperar o acesso no iPhone. Pagamento único, sem cobrança adicional pela versão beta.
Como instalar no iPhone
  1. Abra esta página no Safari.
  2. Toque em Compartilhar.
  3. Selecione Adicionar à Tela de Início e mantenha “Abrir como aplicativo”.
