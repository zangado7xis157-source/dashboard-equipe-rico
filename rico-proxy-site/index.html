FAQ

Dúvidas comuns

Quando o cliente recarrega, recebe outra proxy?

Não necessariamente. Para tráfego residencial dinâmico, a ideia é manter a mesma conta e aumentar o limite de GB dela. O cliente continua usando as mesmas credenciais.

A entrega pode ser automática?

Sim. Após o pagamento ser aprovado, o backend pode criar ou atualizar a conta do cliente e liberar acesso no painel.

Proxy fixa funciona igual?

Não. Produtos estáticos/ISP têm recursos e validade próprios. A base do painel já separa esses produtos para tratarmos renovação individualmente.
